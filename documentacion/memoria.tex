\section*{\color{UPCBlue}\'Indice propuesto de la memoria}
\addcontentsline{toc}{section}{\'Indice propuesto de la memoria}

Esta plantilla inicial contiene la portada y la estructura completa de la
documentaci\'on. El contenido de cada apartado se redactar\'a en las siguientes
iteraciones.

\vspace{0.5cm}
\textbf{Elementos preliminares}
\begin{itemize}[leftmargin=1.1cm,itemsep=0.2em,topsep=0.2em]
    \item Portada.
    \item \'Indice general.
    \item \'Indice de figuras y tablas.
\end{itemize}

\begin{enumerate}
    \item Introducci\'on
    \begin{enumerate}
        \item Contexto de la pr\'actica y motivaci\'on del sistema.
        \item Estructura de la memoria y metodolog\'ia seguida.
    \end{enumerate}

    \item Identificaci\'on del problema
    \begin{enumerate}
        \item Descripci\'on del problema de recomendaci\'on de viajes.
        \item Alcance, supuestos y l\'imites del sistema.
        \item Viabilidad de construir un Sistema Basado en el Conocimiento.
        \item Fuentes de conocimiento utilizadas.
        \item Objetivos del sistema.
        \item Resultados esperados y requisitos que debe cumplir la recomendaci\'on.
    \end{enumerate}

    \item Conceptualizaci\'on
    \begin{enumerate}
        \item Descripci\'on del dominio de viajes personalizados.
        \item Conceptos principales del dominio.
        \begin{enumerate}
            \item Usuario, perfil de viaje y grupo viajero.
            \item Ciudades y caracter\'isticas tur\'isticas.
            \item Alojamientos y calidad de estancia.
            \item Actividades, visitas y gu\'ias de visita.
            \item Conexiones, transportes y etapas del recorrido.
            \item Restricciones obligatorias y preferencias comparativas.
            \item Planes candidatos y planes recomendados.
        \end{enumerate}
        \item Conocimiento experto extra\'ido del dominio.
        \begin{enumerate}
            \item Reglas de sentido com\'un sobre perfiles de usuario.
            \item Criterios de compatibilidad de destinos, alojamientos y transportes.
            \item Criterios para comparar soluciones factibles.
            \item Tratamiento de restricciones incompatibles y no soluci\'on.
        \end{enumerate}
        \item Conceptualizaci\'on apoyada por un modelo de lenguaje.
        \begin{enumerate}
            \item Contexto y prompt de elicitaci\'on de conocimiento.
            \item Preguntas realizadas al experto simulado.
            \item Conocimiento incorporado, adaptado o descartado.
        \end{enumerate}
        \item Descomposici\'on del problema en subproblemas.
        \begin{enumerate}
            \item Adquisici\'on de datos del usuario.
            \item Deducci\'on del perfil, restricciones y preferencias.
            \item Filtrado de recursos compatibles.
            \item Generaci\'on de itinerarios candidatos.
            \item C\'alculo de precio y puntuaci\'on de alternativas.
            \item Selecci\'on de dos planes con ciudades diferentes.
            \item Explicaci\'on del resultado o del caso sin recomendaci\'on.
        \end{enumerate}
        \item Descripci\'on informal del proceso de resoluci\'on.
    \end{enumerate}

    \item Formalizaci\'on
    \begin{enumerate}
        \item Naturaleza del problema y m\'etodo de resoluci\'on escogido.
        \begin{enumerate}
            \item Clasificaci\'on del perfil del usuario.
            \item Generaci\'on, revisi\'on y comparaci\'on de planes.
            \item Justificaci\'on del encaje entre los subproblemas y el m\'etodo.
        \end{enumerate}
        \item Desarrollo de la ontolog\'ia.
        \begin{enumerate}
            \item Dominio, cobertura y preguntas que debe responder.
            \item T\'erminos relevantes del dominio.
            \item Clases, jerarqu\'ia y decisiones de modelado.
            \item Propiedades, atributos y restricciones de valores.
            \item Relaciones entre conceptos.
            \item Instancias necesarias para la base de conocimiento.
        \end{enumerate}
        \item Ontolog\'ia final del sistema.
        \begin{enumerate}
            \item Grafo de la jerarqu\'ia de conceptos.
            \item Descripci\'on detallada de clases.
            \item Descripci\'on detallada de atributos y relaciones.
            \item Correspondencia entre la ontolog\'ia y la representaci\'on en CLIPS.
        \end{enumerate}
        \item Formalizaci\'on del razonamiento por subproblemas.
        \begin{enumerate}
            \item Datos de entrada y hechos de trabajo.
            \item Restricciones duras del viaje.
            \item Preferencias y heur\'isticas de puntuaci\'on.
            \item Construcci\'on del precio total y duraci\'on del viaje.
            \item Elecci\'on de dos recomendaciones diferentes.
            \item Justificaci\'on de preferencias cumplidas y no soluci\'on.
        \end{enumerate}
    \end{enumerate}

    \item Implementaci\'on
    \begin{enumerate}
        \item Organizaci\'on del proyecto y archivos entregados.
        \item Representaci\'on del conocimiento en CLIPS.
        \begin{enumerate}
            \item \texttt{deftemplates} y hechos principales.
            \item Base de conocimiento de ciudades, alojamientos, visitas y conexiones.
            \item Hechos din\'amicos de usuario, candidatos y planes elegidos.
        \end{enumerate}
        \item Funciones auxiliares del sistema.
        \item Reglas y fases del motor de inferencia.
        \begin{enumerate}
            \item Bienvenida y entrevista.
            \item Deducciones expertas.
            \item Generaci\'on de candidatos.
            \item Selecci\'on de recomendaciones.
            \item Salida explicada y cierre del sistema.
        \end{enumerate}
        \item Mecanismos de control y modularizaci\'on del razonamiento.
        \item Decisiones de implementaci\'on relevantes.
        \begin{enumerate}
            \item Restricciones obligatorias frente a preferencias.
            \item C\'alculo num\'erico de precios.
            \item Control de rutas distintas y caso imposible.
        \end{enumerate}
        \item Desarrollo incremental y prototipos.
        \begin{enumerate}
            \item Prototipo inicial.
            \item Extensiones y revisiones intermedias.
            \item Versi\'on final.
            \item Planificaci\'on y organizaci\'on del trabajo del grupo.
        \end{enumerate}
        \item Instrucciones de ejecuci\'on.
    \end{enumerate}

    \item Juegos de prueba y validaci\'on
    \begin{enumerate}
        \item Criterios de selecci\'on de los juegos de prueba.
        \item Cobertura de casos comunes, restricciones y excepciones.
        \item Caso 1: familia con ni\~nos y presupuesto alto.
        \begin{enumerate}
            \item Escenario, objetivo y entrada.
            \item Resultado esperado.
            \item Salida original de CLIPS.
            \item Explicaci\'on del resultado obtenido.
        \end{enumerate}
        \item Caso 2: estudiante que prioriza tren y evita avi\'on.
        \begin{enumerate}
            \item Escenario, objetivo y entrada.
            \item Resultado esperado.
            \item Salida original de CLIPS.
            \item Explicaci\'on del resultado obtenido.
        \end{enumerate}
        \item Caso 3: pareja rom\'antica por aniversario.
        \begin{enumerate}
            \item Escenario, objetivo y entrada.
            \item Resultado esperado.
            \item Salida original de CLIPS.
            \item Explicaci\'on del resultado obtenido.
        \end{enumerate}
        \item Caso 4: grupo de amigos en viaje de fin de curso.
        \begin{enumerate}
            \item Escenario, objetivo y entrada.
            \item Resultado esperado.
            \item Salida original de CLIPS.
            \item Explicaci\'on del resultado obtenido.
        \end{enumerate}
        \item Caso 5: naturaleza y lugares menos conocidos.
        \begin{enumerate}
            \item Escenario, objetivo y entrada.
            \item Resultado esperado.
            \item Salida original de CLIPS.
            \item Explicaci\'on del resultado obtenido.
        \end{enumerate}
        \item Caso 6: restricciones incompatibles y no soluci\'on.
        \begin{enumerate}
            \item Escenario, objetivo y entrada.
            \item Resultado esperado.
            \item Salida original de CLIPS.
            \item Explicaci\'on del resultado obtenido.
        \end{enumerate}
        \item Verificaci\'on del cumplimiento del enunciado.
        \item An\'alisis global de los resultados de prueba.
    \end{enumerate}

    \item Conclusiones
    \begin{enumerate}
        \item Cumplimiento de objetivos.
        \item Fortalezas del sistema construido.
        \item Limitaciones actuales y posibles mejoras.
        \item Aprendizajes sobre ontolog\'ias, reglas y Sistemas Basados en el Conocimiento.
    \end{enumerate}

    \item Bibliograf\'ia y fuentes
    \begin{enumerate}
        \item Material de la asignatura y enunciado.
        \item Fuentes del dominio de viajes utilizadas.
        \item Herramientas y recursos de implementaci\'on.
    \end{enumerate}
\end{enumerate}
